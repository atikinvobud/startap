**Название проекта**
Сервис для управления арендной недвижимостью "Ключник"

**УТП**
Для частных арендодателей мы создаём единый сервис управления арендой, который помогает упростить коммуникацию между арендодателем и арендатором, контролировать платежи, ремонтные заявки и документы, в отличие от привычных мессенджеров (Telegram, WhatsApp) и таблиц, потому что объединяет все ключевые процессы аренды — чат с жильцом, статусы оплат, карточки заявок и хранилище договоров — в одном удобном приложении.
